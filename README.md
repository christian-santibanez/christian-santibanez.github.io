# christian-santibanez.github.io

Portafolio personal de Christian Santibáñez — DevSecOps Engineer · AppSec.

## 🔗 Sitio

[christian-santibanez.github.io](https://christian-santibanez.github.io)

## 🛠️ Stack

- React 18
- Vite
- Tailwind CSS
- Lenis (smooth scroll)

## ✨ Características

- Diseño responsivo mobile-first
- Modo oscuro / claro con persistencia en localStorage
- Secciones: Hero, Sobre mí, Servicios, Certificaciones, Proyectos, Contacto
- Formulario de contacto con Web3Forms + hCaptcha
- Deploy en GitHub Pages

## 🚀 Desarrollo local

```bash
npm install
npm run dev
```

## 📦 Deploy

```bash
npm run deploy
```
